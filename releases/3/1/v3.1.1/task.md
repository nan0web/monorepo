# 🚀 Mission: E5-Instruct Embedding Prefix Integration & Contextual Chunking

[English version](task.en.md)

## 🏁 Overview

Мета цього релізу — оптимізувати якість семантичного пошуку в базі знань монорепозиторію. Ми впроваджуємо автоматичне префіксування `"query: "` та `"passage: "` для моделі `text-embedding-multilingual-e5-large-instruct` на рівні класу `Embedder`, а також збагачуємо текстові фрагменти (чанки) контекстними метаданими (назва файлу, ієрархія розділів) перед генерацією векторів.

Видалення `.editorconfig` всередені пакетів і додатків замість єдиного у монорепі.

## 👥 User Stories

- **Як розробник (User Space)**, який шукає інформацію через `SearchSourcesIntent`, Я хочу отримувати точні, контекстуально релевантні результати пошуку без зайвого шуму, оскільки запит автоматично префіксується для інструктивної моделі.
- **Як користувач системи індексації**, Я хочу, щоб індексовані чанки зберігали інформацію про своє походження (назва файлу, розділ), навіть якщо вони були розбиті на параграфи, щоб векторний пошук знаходив їх за контекстуальними зв'язками.

## 🏗 Data-Driven Architecture

1. **`Embedder`**: додає параметризовану підтримку префіксів `{ type: 'query' | 'passage' }` для моделей родини `e5`.
2. **`MarkdownIndexer`**: адаптує виклики `embedBatch` з префіксом `'passage'`, а також збагачує текст кожного чанку метаданими про файл перед векторизацією.
3. **`SearchSourcesIntent`**: адаптує виклик `embed` з префіксом `'query'`.
