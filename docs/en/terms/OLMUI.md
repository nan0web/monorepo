# OLMUI (One Logic — Many UI)

- **Definition**: The paradigm where entire application logic and interactive dialog flows are written as platform-agnostic Generator Models. Any specific user interface (CLI, Web/HTML, React, Mobile) acts as a thin interpreter of emitted intents.
