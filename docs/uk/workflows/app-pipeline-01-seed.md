# 🏭 `app-pipeline-01-seed` (Seed Architect)

> **Призначення:** Перший крок розробки OLMUI додатка. Цей субагент перетворює будь-яке "розмите" побажання Користувача (Намір) на структурований документ `seed.md`.

## Інструкція для Агента

Коли Користувач викликає цей workflow і дає опис нового продукту:

1. **Аналіз Наміру:**
   - Чітко визнач сутність (Subject), дію (Action) та мету.
   - Запитай себе: "Яка інформація (поля) дійсно потрібна від користувача, а яку ми можемо отримати автоматично?"
   - Фільтр мови Наміру: прибери будь-які частки "не" з опису (замість "щоб не було помилок", пиши "має працювати ідеально").

2. **OLMUI Проєктування:**
   - Подумай про те, яким буде генератор `async *run()`. Які інтенції (`ask()`, `progress()`, `log()`) він видаватиме?
   - Які поля будуть у `static schema` для валідації цих відповідей?

3. **Створення `seed.md`:**
   **МЕХАНІЧНА ДІЯ:** Ти ЗОБОВ'ЯЗАНИЙ створити або оновити файл `seed.md` у теці `docs/` (або в корні додатка).

   Формат файлу `seed.md` має бути таким:
   ```markdown
   # Seed: [Назва Додатка]
   
   ## 1. Сутність та Мета
   [Опис наміру одним абзацом]

   ## 2. Model-as-Schema (Схема Даних)
   - `поле1` (тип, підказка UI: hover, radio, date)
   - `поле2`

   ## 3. Каркас Роботи (Діаграма)
   [ОБОВ'ЯЗКОВО вставте тут Mermaid Flowchart діаграму, яка візуально зображує логіку взаємодії користувача та системи для кращого сприйняття. Наприклад `graph TD...`]

   ## 4. Генератор (Flow)
   1. progress: Ініціалізація
   2. ask: Валідація `поле1`
   3. progress: Збереження в State
   ...

   ## 4. User Stories
   [Посилання на файл `user-stories.md`, або безпосередньо детальний список з 15-30 (числа) User Stories, які описують усі можливі сценарії використання додатку від початку до кінця. З цих Story пізніше будуть генеруватись автоматичні тести `*.story.js`. Більше інформації про вимоги до написання сценаріїв: `workflows/docs-stories.md`]
   ```

## Завершення:
Після запису файлу `seed.md` та `user-stories.md`, запропонуй Користувачу відкрити НОВИЙ чат і запустити `/app-pipeline-02-model`.
