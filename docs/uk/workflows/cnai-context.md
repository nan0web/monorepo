# 🧠 ОПТИМІЗАЦІЯ КОНТЕКСТУ AI-АСИСТЕНТА

Для збереження максимальної довжини контекстного вікна (яке швидко вичерпується при читанні `source` файлів):

## Правила

1. **Docs-First Principle**: Перед взаємодією з будь-яким незнайомим пакетом або додатком, Агент **ОБОВ'ЯЗКОВО** повинен спочатку прочитати його `README.md` або `project.md`. Тут знаходяться всі приклади та пояснення того, як пакет працює.
2. **Types-First Principle**: Для вивчення доступного API пакета, Агент **ОБОВ'ЯЗКОВО** має дивитись у файли підказок типів (`types/*.d.ts`). Типи повністю описують інтерфейс, тому немає жодної потреби читати вихідний код.
3. **Мінімалізм Читання (Strict No-Source Rule)**: **КАТЕГОРИЧНО ЗАБОРОНЯЄТЬСЯ** читати детальні вихідні файли (`src/**/*.js`), якщо ви тільки інтегруєте пакет. Заглядати в `src/` дозволяється виключно у випадках глибокого відлагодження (debugging) або прямої модифікації логіки цього конкретного пакета.
4. **Paginators & Search**: Для дослідження великих наборів даних або сесій використовуйте утиліти формату CLI з підтримкою пошуку або пагінації, щоб не завантажувати гігабайти тексту в пам'ять.
5. **Data Fetching Constraint (--level 1)**: При тестуванні та дослідженні конфігурацій даних через команди `nan0web fetch`, **ОБОВ'ЯЗКОВО** використовуйте параметр обмеження глибини виводу `--level 1` (або `2`), щоб уникнути переповнення та засмічення контекстного вікна.

---

## 🤖 Important Note for Autonomous Agents & Testing 🤖

При використанні CLI-інструментів для дослідження даних (наприклад, `nan0web fetch` або `nan0web dir`):

- **ОБОВ'ЯЗКОВО** використовуйте параметр обмеження глибини виводу `--level 1` (або `2`).
- Це запобігає засміченню та миттєвому переповненню вашого контекстного вікна гігантськими вкладеними структурами YAML/JSON.
- Повна серіалізація (`--level 0` або без параметра) дозволена лише тоді, коли вам конкретно потрібні всі дані з документа для подальшої обробки.
