# 🏭 `app-pipeline-06-ui-chat` (Chat Adapter)

> **Призначення:** Шостий крок конвеєра. Створення Chat-інтерфейсу, в ідеалі з доступом до CLI інструменту.

## Інструкція для Агента

Коли Архітектор викликає цей workflow:

1. **Перевірка передумов:**
   - CLI-адаптер (Крок 5) успішно імплементовано та перевірено.

2. **Створення Chat Адаптера (LLiMo Protocol):**
   - Створити `src/ui/chat/index.js` як точку входу.
   - Chat-адаптер повинен мати безпосередній доступ до UI CLI команд. Він так само дивиться `help` та завантажує цю інформацію в своє перше повідомлення, щоб розуміти всі налаштування та контекст системи (без галюцинацій).
   - Він повинен вміти приймати запити і викликати UI CLI команди, очікувати від них відповідь і сигналізувати користувачеві.
   - **Long-Running Operations:** Для довгих операцій (назв. `Progress Intents`) Chat-адаптер має встановлювати `timeout`, щоб періодично перевіряти стан і надсилати "snapshot" прогресу користувачеві (наприклад, кожні `N` секунд), щоб UI був живим і відображав актуальний стан операції.

3. **Тестування:**
   - Покрити chat-адаптер канонічним сценарним тестом, де емулюється LLM-відповідь і перевіряється, чи правильно парсяться інтенції (`Intents`).

4. **Перевірка:**
   - Всі локальні тести зелені (`bun test src/ui/chat`).

## Завершення:
Зафіксувати версію тегом та перейти до `/app-pipeline-07-ui-web`.
