# 🔄 Ворклоу: Відновлення project.md (Restore Project)

Цей workflow викликається тоді, коли `bin/indexator.js` або розробник фіксують відсутність `project.md` у пакеті чи додатку екосистеми.
Мета процесу — відновити або створити з нуля `project.md` за стандартом `universal-project.md`, витягнувши історичний контекст пакету.

## 1. Атрибутика Контексту

- **Вимога до чату:** 🔴 NEW CHAT (Обнулений контекст).
- **Необхідні файли на вхід:**
  - `packages/{НазваПакету}/README.md` (якщо є)
  - `packages/{НазваПакету}/system.md` (якщо є, застарілий формат)
  - `packages/{НазваПакету}/package.json` (щоб дізнатись залежності та короткий опис)
  - `@[/project-md]` (для розуміння стандарту)
  - `docs/uk/universal-project.md` (шаблон)

## 2. Завдання Агента (Architechnomag)

1. Проаналізувати наданий контекст (код пакету, його залежності, README).
2. Зрозуміти **Місію (Фаза 1)** та архітектуру пакету (як він працює зараз).
3. Якщо пакет має старий `system.md` — перенести всю ключову архітектурну інформацію з нього у файл `docs/uk/project.md`.
4. Заповнити `docs/uk/project.md` відповідно до **5 Фаз** із універсального шаблону. Якщо якісь фази відсутні (наприклад, пакет не має CLI або UI) — чітко вказати: "Ця фаза наразі не реалізована в пакеті".
5. Створити точну англійську копію документа у файлі `docs/en/project.md`.
6. Створити в корні пакета файл-роутер `project.md`, який **обов'язково** повинен починатися з **YAML Frontmatter** (поля `description` та `tags`) для `indexator`, а нижче містити лише посилання на мовні версії:

   ```yaml
   ---
   description: Короткий архітектурний опис пакету/додатку, 1-2 речення
   tags: [auth, core, backend, frontend тощо]
   ---

   # 🏗️ Architecture: Назва Пакету

   - [🇺🇦 Українська (Оригінал)](./docs/uk/project.md)
   - [🇬🇧 English (Translation)](./docs/en/project.md)
   ```

7. Використати інформацію із README або `package.json` та згенерувати цей короткий опис для YAML-фронтметтеру, якщо він взагалі не існує.

## 3. Результат

1. Створено ієрархію: кореневий `project.md` та тексти у `docs/uk/project.md` і `docs/en/project.md`.
2. Якщо дані були перенесені з `system.md` успішно — замінити його зміст на `Read [project.md](./project.md)`.
3. Сповістити розробника:
   > ✅ Документ `project.md` відновлено та створено в новій ієрархії `docs/uk`! Запусти `npm run index` (або `node packages/0HCnAI.framework/bin/indexator.js`), щоб оновити екосистемний індекс.
