# 🧘‍♀️ Workflow: Інтерактивна Діагностика та Тестування (Agent as UI)

> **Призначення:** Стандартизований регламент для AI-агента (в Antigravity, Вайбі або будь-якому чат-середовищі) для проведення тестування та анкетування людини за Markdown-файлом опитувальника.  
> **Еталонний файл анкет:** `data/tests/myt-12-senses.md` (або будь-який інший сумісний Markdown-тест).

---

## 🏛 Архітектурний Принцип: Агент — це UI (Agent as User Interface)

Агент НЕ виводить усю анкету полотном тексту і НЕ змушує людину самостійно підраховувати бали.  
Агент виступає **дзеркалом і провідником (Ментором/Інтерфейсом)**, що крок за кроком веде респондента.

---

## 📋 Правила Взаємодії для Агента

### 1. Покрокова Видача (One-at-a-Time)
- Агент бере **рівно 1 запитання** за одну репліку (або 1 категорію з 3 перехресними проекціями при текстовому режимі).
- **Сувора заборона:** Заборонено вивалювати людині більше одного кроку/запитання за раз, якщо вона явно про це не попросила.

### 2. Рандомізація (Shuffle)
- Якщо у frontmatter анкети вказано:
  ```yaml
  shuffle:
    - questions
    - answers
  ```
- Агент **перемішує порядок варіантів відповідей**, щоб людина не бачила фіксованого патерну `[1.0, 0.5, 0.0]`.
- Бали фіксуються за суттю варіанту, а не його поточною літерою чи номером у меню!
- Принцип розподілу ваги автора:
  - Суверенний/чистий стан: **1.0**
  - Компроміс / его-компенсація: **0.5**
  - Деструкція / страх / параліч: **0.0**

### 3. Режими Вводу в Середовищах

#### А. Середовище Antigravity IDE (Interactive UI Modal)
- Агент **ЗОБОВ'ЯЗАНИЙ** викликати нативний інструмент `ask_question`.
- `question`: текст запитання та контекст (номер кроку, сенсор/стан).
- `options`: перемішані варіанти відповідей.
- `is_multi_select: false`.
- Це створює нативну кнопку вибору в IDE, виключаючи ручний набір тексту.

#### Б. Середовище Зовнішнього Чату (Вайб / Веб / CLI / Мобільний)
- Агент формує чітке лаконічне повідомлення з варіантами `1)`, `2)`, `3)` (або `A)`, `B)`, `C)`).
- Очікує короткої відповіді від користувача (цифра, літера або голосове/текстове пояснення).

## 🧮 Фіксація та Розрахунок Результатів (Тріангуляція)

1. Після отримання кожної відповіді агент зберігає вибір у внутрішньому стані сесії (Memory / Session Model).
2. Після завершення всіх 36 запитань (12 категорій по 3 питання) агент виконує розрахунок:
   - **Правило 0-множника:** Якщо у категорії є хоча б один вибір із балом `0.0`, оцінка категорії пеналізується до `min_score = 0.05`.
   - **За відсутності нулів:** середнє геометричне 3 відповідей:
     $$P_k = \sqrt[3]{q_1 \cdot q_2 \cdot q_3}$$
   - **Метрики:**
     $$S_{ext} = \sqrt[7]{\prod_{i=1}^{7} V_i}$$
     $$S_{int} = \sqrt[4]{\frac{E_1 \cdot E_3 \cdot E_4 \cdot E_5}{1 + E_2}}$$
     $$\Sigma = \sqrt{S_{ext} \times S_{int}}$$
     $$\hat{H}_{eff} = \Sigma \times \hat{H}_{base}$$
3. Агент формує людині фінальний діагностичний звіт:
   - Підсумковий бал $\Sigma$ та рівень синхронізації (`Творець / Пробуджений / Матричний`).
   - Карта 7 зовнішніх сенсорів та 5 внутрішніх станів.
   - Зони витоку енергії (де виявлено нулі або пенальті).
