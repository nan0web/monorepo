# Взаємодія з кодовою базою

1. Використовуємо гіт для всіх проєктів.
2. Використовуємо памʼять проєкта у форматі `docs/{locale}/**/*.md` з індексами.
3. Використовуємо памʼять по меті і задачах сесії, якщо увімкнено режим релізів, то це має бути реліз `releases/{major}/{minor}/v{major}.{minor}.{patch}/*.md` або `next.md`.
4. Всі відгуки архітектора записуємо у `backlog.md` в релізі або `next.md`. Важливо записувати у кінець файлу кожне уточнення або помилку, яка вимагає змін в коді, для розуміння якості виправлення релізу за журналом `feedback` і повторюванням помилок.
