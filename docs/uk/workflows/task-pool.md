# 🔥 ПРОТОКОЛ ПУЛУ ЗАВДАНЬ (TASK POOL)

> **"Прозорість — це швидкість"**

Для забезпечення безперервності розробки між сесіями та прозорості прогресу, кожен проект ПОВИНЕН мати файл `next.md` з актуальним статусом.

## Правила

1.  **Читання при старті**: Агент ЗАБОВ'ЯЗАНИЙ прочитати `next.md` на самому початку кожної сесії.
2.  **Структура Завдань**:
    - Завдання мають унікальні ID (напр. `PG-1`, `AUTH-2`).
    - Кожне завдання має опис та чекбокс (`[ ]` / `[x]`).
3.  **Логування Нових Завдань**: Будь-яке прохання користувача ("зроби це", "виправ те"), яке не виконується миттєво, МАЄ бути негайно додане в Пул Завдань в `next.md`.
4.  **Звітність (Check-out)**: В кінці сесії Агент оновлює `next.md`, відмічаючи виконане, та коротко резюмує залишок завдань.
5.  **Пріоритезація**: Пул завдань — це черга. Агент працює по ній, якщо користувач не надав інших інструкцій.
