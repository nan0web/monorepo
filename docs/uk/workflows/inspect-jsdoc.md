# Zero-Hallucination JSDoc Validator Subagent Workflow

Цей робочий процес розроблено для використання Субагента з метою перевірки файлів домену (Domain Models) на відповідність правилам JSDoc.

Згідно з нашими стандартами:

1. Усі поля повинні бути в рамках формату Model-as-Schema.
2. JSDoc коментарі до полів мають починатися з `/** @type {Тип} Опис на мові проекту */`.
3. Мова опису JSDoc для доменних моделей повинна відповідати **основній мові документації проекту** (напр., українська для Банку, англійська для глобальних модулів). Шлях перевірки: всі файли всередині `src/**/*.js` оминаючі `src/**/*.test.js`.

## Кроки запуску

1. Запустити Субагента з відповідним запитом, передавши йому директорію як контекст:
   - "Твоє завдання: прочитати всі файли в каталозі `src/domain/`. Якщо JSDoc коментарі відсутні, є неповними або написані не тією мовою, що вимагає проект - додай їх або виправ. Тип треба зазначати обов'язково."
2. Дочекатися завершення роботи Субагента та збереження змін у файлах.
3. Проаналізувати `git diff` для верифікації внесених змін.
4. Запустити тести, щоб впевнитися, що зміни коментарів нічого не зламали.
