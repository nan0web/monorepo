# 🚀 Ворклоу: Release Contract & Pipeline Protocol

Цей документ є єдиним джерелом правди для побудови та виконання релізів у проєктах екосистеми `NaN•Web`.

Кожен реліз ізолюється у власній трирівневій директорії версіонування:
`releases/{major}/{minor}/v{major}.{minor}.{patch}/`

Він обов'язково містить три складові:

1. **`task.md`** — декларація місії, архітектури та переліку завдань (Data-Driven Contract).
2. **`task.spec.js`** — контрактні тести специфікації релізу (Contract-First).
3. **`pipeline.md`** — лаконічний конвеєр для автономного запуску виконання та повної верифікації.

---

## 1. Специфікація `task.md` (Місія та Специфікація)

Файл `task.md` містить суворий YAML Frontmatter для автоматичного парсингу утилітами `nan0ai task`, `@nan0web/inspect` та LLM-агентами.

- **Еталонний шаблон:** [templates/task.md](./templates/task.md)

---

## 2. Специфікація `task.spec.js` (Контрактні тести)

Контрактний тест описує вимоги релізу через стандартний нативний раннер `node:test`.

### Правила `task.spec.js`:

- Прямі імпорти: імпортує функції/моделі безпосередньо з вихідного коду проєкту (`src/`).
- Тестує конкретні сценарії з `task.md` (не є мета-тестом).
- Повинен виконуватися швидко (без важких зовнішніх затримок, з mock/in-memory даними).
- **Еталонний шаблон:** [templates/task.spec.js](./templates/task.spec.js)

---

## 3. Специфікація `pipeline.md` (Конвеєр виконання)

`pipeline.md` — це конвеєр послідовного виконання, який зчитується утилітою `nan0ai pipeline`.
Кожен крок позначається заголовком другого рівня `##`, а виконувана bash-команда — блоком коду ` ```bash `.

### Ключові принципи:

- **Усі шляхи відносні**: команди виконуються у контексті директорії релізу (де лежить `pipeline.md`).
- **Синхронізація виконання**: спочатку швидка перевірка синтаксису, потім контракт, далі виконання завдання агентом, наприкінці — повна перевірка проєкту.
- **Поліглотність та Агностичність**: протокол однаково безшовно працює з Node.js/JavaScript, Python/Pytest, Rust/Cargo або CLI-інструментами.
- **Еталонні шаблони:**
  - **Node.js / JS:** [templates/pipeline.md](./templates/pipeline.md) | Контракт: [templates/task.spec.js](./templates/task.spec.js)
  - **Python / Mistral-Vibe:** [templates/pipeline.python.md](./templates/pipeline.python.md) | Контракт: [templates/test_task.py](./templates/test_task.py)

---

## 4. Запуск Конвеєра

Запуск усього циклу з кореня репозиторію або проєкту:

```bash
nan0ai pipeline releases/{major}/{minor}/v{X.Y.Z}/pipeline.md
```

Або автономно через Vibe / Antigravity `/goal`:

```bash
vibe -p "Запусти та виконай конвеєр releases/0/5/v0.5.1/pipeline.md" --trust --auto-approve
```
