# 💎 NaN•Format (Нано Формат)

- **Визначення**: Прозорий, ультра-швидкий текстовий формат зберігання схем та документів у базах даних NaN0Web (`.nan0`). Він поєднує виразний та дружній синтаксис YAML із продуктивністю бінарних парсерів.
- **Реалізація**: [`@nan0web/db`](../../../packages/db) та [`@nan0web/db-fs`](../../../packages/db-fs)

---

## ⚡ Ключові Переваги та Філософія

1. **🚀 30x Продуктивність**: 
   Парсер `NaN0-Format` працює до **30 разів швидше за стандартний повноваговий YAML-парсер**, оскільки він оптимізований під структуровані ключ-значення масиви та FrontMatter без надлишкових обгородок.
2. **🧩 100% Збереження YAML-синтаксису**: 
   Зберігає повністю зрозумілий людині вигляд (без дужок `{}` чи лапок `""`), легко редагується у будь-якому текстовому редакторі та є ідеальним для Git-дифів.
3. **🤖 ШІ-Оптимізованість (AI-First)**: 
   Кожен файл `.nan0` є живим документом знань. На відміну від бінарних форматів, LLM-агенти можуть напряму читати, модифікувати та валідувати файли `.nan0` без додаткових конвертерів.

## 🔍 Архітектурне Порівняння: NaN0-Format vs MongoDB (BSON & WiredTiger)

### Як працює MongoDB?
- **Бінарна упакованість (BSON)**: MongoDB НЕ зберігає відкриті JSON/YAML текстові файли на диску. Вона конвертує JSON у бінарну структуру **BSON** (Binary JSON) для швидшого типування та сканування.
- **Движок WiredTiger**: Фізично MongoDB упаковує тисячі BSON-документів у бінарні блоки даних (файли `.wt`) з B-Tree індексами та журналами (WAL). Для Git чи ШІ-агентів ці файли є бінарним «чорним ящиком».
- **Файловий Шардінг (Sharding)**: MongoDB розбиває колекційні дані на розрізи (Chunks) і розподіляє їх по шард-серверах через шард-ключі.

### Чому NaN0-Format кращий для Суверенних Систем?
| Критерій | MongoDB (BSON / WiredTiger) | NaN0-Format (`.nan0` + DBFS) |
| :--- | :--- | :--- |
| **Формат зберігання** | Бінарні блоки `.wt` | Відкриті текстові файли `.nan0` |
| **Читабельність для людини та ШІ** | ❌ Потрібні інструменти / CLI | ✅ 100% прозорий текст для LLM та Git |
| **Швидкість читання** | Швидко (бінарно) | ⚡ До 30x швидше за YAML |
| **Контроль версій (Git Diff)** | ❌ Неможливо (бінарний файл) | ✅ Точний рядковий Git diff |
| **Шардінг на Файловій Системі** | Через серверні ноди та WiredTiger | Нативний каскад директорій (`/data/uk/_/`) |
