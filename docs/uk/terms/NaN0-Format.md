# NaN•Format (Нано Формат)

- **Визначення**: Формат схем бази даних, що представляє структуроване розширення даних через успадкування та вирішення посилань в обмеженому синтаксисі YAML. Він є основою для побудови повністю data-driven систем у NaN•Web.
- **Реалізація**: [packages/db](../../../packages/db) та [packages/db-fs](../../../packages/db-fs)
