# OLMUI (One Logic — Many UI / Одна Логіка — Багато Інтерфейсів)

- **Визначення**: Парадигма, де інтерактивний життєвий цикл програми будується як абстрактний генератор інтентів. Будь-який візуальний інтерфейс (термінальний CLI, веб-сторінка, мобільний додаток) є лише тонкою оболонкою-інтерпретатором цих інтентів.
