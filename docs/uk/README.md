## 🏛️ Архітектурний Детермінізм (OLMUI & Model-as-App)

Основа всієї платформи — сувора та універсальна детермінованість програмного забезпечення:

1.- **Total Logic Isolation (TLI)**: Бізнес-логіка та валідація суворо відокремлені від рендерингу.
- **Model-as-Schema / Model-as-App**: Опис даних, валідація та поведінка єдині в JS-моделях.
- **Data-Driven Applications**: Усі екрани, макети та сторінки відмальовуються з роутерифікацій та моделей, збережених у будь-якій агностичній базі даних через протокол `db.fetch()`.
- **One Logic — Multiple User Interfaces (OLMUI)**:

   Фундаментальна триада детермінізму:
   - **Моделі**: Алгоритми та бізнес-домен.
   - **Стилі та Компоненти**: Оформлення та представлення даних.
   - **Навігація**: Розкладання компонентів по сторінках для зручності людини.

Завдяки цьому єдиний шар бізнес-логіки за замовчуванням **одразу працює у всіх можливих UI-реалізаціях**:

- 🖥️ **CLI** (Інтерактивний термінал)
- 💬 **Chat** (Автономні LLM-агенти)
- 🌐 **Web & SSG** (Next.js / Turbopack / Vanilla DOM)
- ⚛️ **React / Lit** (Веб-компоненти)
- 🎙️ **Voice** (Голосовий інтерфейс)

## 🚀 Швидкий Старт

### 1. Підготовка середовища

Переконайтеся, що у вас встановлено [pnpm](https://pnpm.io/). Ми використовуємо pnpm workspaces для ефективного керування залежностями.

```bash
pnpm install
```

pnpm є обовʼязковим менеджером

### 2. Інтеграція з ШІ (Рекомендовано)

Для «Суверенної Розробки» з ШІ-агентами потрібно надати їм доступ до бази знань проекту.

1.- **Налаштування EMBEDDER_URL**:

   Вкажіть адресу вашого локального сервера ембедінгів (LM Studio або Ollama).

   **Для Linux / macOS (zsh, bash):**
   ```bash
   export EMBEDDER_URL="http://localhost:1234/v1"
   ```
   **Для Windows (Command Prompt):**
   ```cmd
   set EMBEDDER_URL=http://localhost:1234/v1
   ```
   **Для Windows (PowerShell):**
   ```powershell
   $env:EMBEDDER_URL = "http://localhost:1234/v1"
   ```

1.- **Індексація воркспейсу**:

   ```bash
   pnpm run ai:index
   ```

1.- **Налаштування MCP сервера**:

   ```bash
   pnpm run ai:setup
   ```

### 3. Глобальний доступ до ШІ (nan0ai)

Ви можете встановити асистента глобально, щоб мати доступ до знань NaN•Web з будь-якої точки системи:

```bash
pnpm add -g @nan0web/ai
```
> 💡 **Примітка:** Якщо під час запуску виникає помилка завантаження нативних біндінгів (`Could not locate the bindings file` для `hnswlib-node`), виконайте: `npm rebuild hnswlib-node --prefix $(pnpm root -g)/..`

Тепер команда `nan0ai` доступна всюди. Спробуйте:

```bash
nan0ai search "Як створити новий компонент?"
```

Скрипти ШІ доступні
