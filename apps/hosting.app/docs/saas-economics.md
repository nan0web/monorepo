# Економіка та окупність SaaS хостингу на базі NaN•Panel

Цей документ фіксує фінансову модель, щільність розміщення клієнтів (Tenant Density) та окупність інфраструктури при використанні стеку Caddy + Bun.js + SQLite/db-fs.

---

## 💶 Собівартість інфраструктури (на базі Hetzner Cloud)

Для обслуговування дрібних бізнес-клієнтів (до 1000 унікальних відвідувачів на день на один сайт) оптимальним є наступний серверний стек:

1. **Сервер VPS: Hetzner CX22 (Shared CPU)**
   * **Процесор:** 2 vCPUs (Intel)
   * **Пам'ять:** 4 GB RAM
   * **Диск:** 40 GB NVMe SSD
   * **Вартість:** **~€3.79 / місяць** (плюс ПДВ)
2. **Додатковий диск (Block Storage Volume)**
   * **Об'єм:** 50 GB NVMe (монтується в `/www/vmail/` під поштові скриньки)
   * **Вартість:** **~€2.50 / місяць**

**Сумарна собівартість інфраструктури: ~€6.30 / місяць.**

---

## 📈 Розрахунок щільності та прибутку (Tenant Density)

Завдяки архітектурі **NaN•Panel** (Scale-to-Zero для процесів Bun та 0 МБ споживання пам'яті базою даних db-fs у простої) ми маємо надвисоку щільність розміщення додатків.

| Показник | Значення | Примітки |
| :--- | :--- | :--- |
| **Максимальна кількість сайтів** | **30–50 сайтів** | При середньому споживанні Bun-процесу ~15 МБ під час активності |
| **Максимальна кількість поштових скриньок** | **50 скриньок** | При квоті 1 ГБ на одну скриньку користувача |
| **Тариф для кінцевого клієнта** | **€5.00 / місяць** | Включає: 1 статичний/API сайт + 1 поштова скринька |
| **Кількість клієнтів для окупності** | **2 клієнти** | Повністю перекривають витрати на сервер (€10.00 доходу проти €6.30 витрат) |

### Фінансова модель при заповненні сервера на 40% (20 клієнтів):
* **Місячний дохід:** 20 клієнтів * €5.00 = **€100.00 / місяць**
* **Витрати на сервер:** **€6.30 / місяць**
* **Чистий прибуток:** **€93.70 / місяць**
* **Рентабельність (Margin):** **~93.7%**

## 🔧 Механізм взаємодії в коді

Кожен новий клієнт описується як окремий YAML-документ у базі даних `data/tenants/`:
```yaml
id: "client-icesquare"
domain: "icesquare.legalgreenplanet.tech"
proxyPort: 3001
mailboxes:
  - user: "icesquare"
    quotaGb: 1
```
Ядро `hosting.app` зчитує ці конфіги та автоматично оновлює Caddy API та SQLite базу поштових користувачів Dovecot/Postfix, автоматизуючи білінг та надання послуг.

---

## 🚀 Додаткові послуги (Upsells) та лімітування ресурсів

Ціна **€5.00 / місяць** є чудовою базовою ціною (Entry Price) для мікробізнесу. Для збільшення середнього чеку (ARPU) платформа реалізує модель додаткових покупок:

### A. Модель Допродажів (Upsell Model)
* **Додаткові 10 GB диску (пошта/файли):** **+€1.00 / місяць**
* **Додатковий домен (з SSL):** **+€1.50 – €2.00 / місяць**
* **Додаткова поштова скринька:** **+€1.00 / місяць**

### Б. Автоматичне застосування та обмеження (Quotas & Limits)
1. **Дискові квоти:** 
   При зміні `quotaGb` у кабінеті користувача білінг-система оновлює YAML-файл клієнта. Ядро `hosting.app` запускає системну команду для оновлення квоти користувача в Dovecot (Maildir quota limit) без перезавантаження сервісів.
2. **Контроль доменів:**
   Кількість активних доменів перевіряється сервером Bun при спробі додати новий домен. Якщо ліміт перевищено, користувачу пропонується доплата. При оплаті ядро викликає `CaddyServerAdapter.addDomain()` для миттєвої реєстрації SSL.
3. **Обмеження користувачів (Rate Limits):**
   На рівні Caddy/Bun встановлюється ліміт запитів (Rate Limiting) за IP та доменом клієнта, щоб один перевантажений сайт не впливав на роботу інших сусідів по VPS (Noisy Neighbor Protection).
