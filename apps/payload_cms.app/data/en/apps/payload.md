# Payload CMS App

The `@nan0web/payload-cms.app` application provides seamless integration of `Model-as-Schema` domain definitions with Payload CMS 3.x.

## Features:
- **Collection Generation:** Two-way translation of field types, relationships, and blocks.
- **Automated Seeding:** Loading structured data (YAML, NAN0, JSON, Markdown).
- **Custom UI Components:** Preconfigured ImageCell, BooleanCell, and MapCell components.
