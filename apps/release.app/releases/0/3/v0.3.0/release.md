# v0.3.0 — CLI Release Inspector & Multi-Format Validator

> **Цільовий додаток:** `apps/release.app` та ядро `@nan0web/release`  
> **Контекст розробки:** Створення консольного інструменту інспекції та валідації релізів (`ValidateCommand`) на базі `ModelAsApp` з використанням ядра `@nan0web/release` (`PMaCParser`, `ReleaseModel`, `ReleaseAuditor`), підтримкою виводу у 4 форматах (`text`, `json`, `nan0`, `csv`) та експорту у файл через `--output`.

---

## 1. Архітектурні Контракти та Принципи

1. **Model-as-App Контролер (`ValidateCommand`):**
   - Успадковує `ModelAsApp` з `@nan0web/ui`.
   - Позиційний аргумент `target`: шлях до каталогу `releases/` або кореню проєкту/монорепозиторію.
   - Підтримка опції `--format` (`text` | `json` | `nan0` | `csv`, за замовчуванням `text`).
   - Підтримка опції `--output=<file>` для збереження звіту у файл через `db.saveDocument` / `db.writeFile`.
2. **Сканування Релізів (Flat & Nested):**
   - Підтримка як пласкої структури `releases/v1.0.0/`, так і вкладеної за стандартом PMaC `releases/{major}/{minor}/v{major}.{minor}.{patch}/`.
   - Сканування окремого шляху або всіх зареєстрованих у `releases.txt` проєктів.
3. **PMaC Валідація за Еталоном:**
   - Парсинг Markdown-специфікацій (`release.md`, `task.md`) через `PMaCParser`.
   - Валідація наявності версії, заголовка, завдань, критеріїв прийомки, паритету та метрик у `user.md` через `ReleaseAuditor`.
4. **Мульти-форматний Рендеринг:**
   - `text`: Кольоровий консольний звіт із бейджами, статистикою та інструкціями щодо виправлення.
   - `json`: Машиночитний структурований JSON для CI/CD та Payload CMS.
   - `nan0`: Компактний декларативний YAML/NaN0 формат.
   - `csv`: Табличний експорт паритету та завдань для електронних таблиць.
5. **Zero-Procedural Code & TDD:**
   - Жодного прямого `fs`, робота виключно через інжектовану базу `@nan0web/db`.
   - 100% покриття тестами `*.story.js` (In-Memory DB) та контрактними `task.spec.js`.
