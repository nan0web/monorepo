# 📋 Завдання та Критерії Прийомки (v0.1.0)

  - Список усіх завдань з `release.md` / `task.md` із чекбоксами `[x]` / `[ ]`.
  - Журнал сесій та відгук архітектора з `user.md`.
  - Повні метрики часу, ітерацій та статусів.
