# 🚀 Mission: Universal Semantic Exporter Pipeline (v3.8.0)

## 🏁 Overview (Огляд)

Реліз v3.8.0 додає універсальну команду експорту контенту `visnyk export` (та `share export`) до CLI застосунку `share.app`.
Команда орієнтована на автономну семантичну маршрутизацію файлів формату Markdown (щоденники, глави книги «мИть», уроки курсу «Суперінтелект») за конфігураційними потоками (`streams`) у `.nan0` / `.yaml` файлах.

---

## 🔑 Ключові Архітектурні Вимоги

### 1. Універсальна команда `export` та Zero-FS
- Команда викликається лаконічно:
  ```bash
  visnyk export --config=arch/diary/_.nan0 --path=arch/diary/2026/11/04/story.md
  ```
  або пачкою за шаблоном дат/шляхів:
  ```bash
  share export --config=arch/diary/_.nan0 --target=all
  ```
- Жодних прямих викликів `fs` у доменній моделі — робота виключно через інжектовану базу `this.$db` (`@nan0web/db`).

### 2. Повна Діагностика Невідомих Тегів (Comprehensive Tag Linter)
- Якщо у документі зустрічаються теги, які **не зареєстровані** в жодному з потоків конфігурації:
  - Система **НЕ** падає на першому ж тегу.
  - Проводиться повний скан всього документа (або пачки файлів).
  - Формується єдиний структурований звіт з усіма незареєстрованими тегами, номерами рядків та заголовками секцій:
    ```
    🚨 ПОМИЛКА ВАЛІДАЦІЇ ТЕГІВ: Знайдено 3 незареєстровані теги:
      - #новий_тег (Рядок 45, Секція "## 2. Економічна Філософія")
      - #крипто_ідея (Рядок 78, Секція "## 3. Крипта vs Фіат")
      - #невідоме (Рядок 112, Секція "## 4. Підсумки")
    Експорт заблоковано для гарантії суверенності даних!
    Додайте їх у відповідні streams у вашому _.nan0 файлі.
    ```

### 3. Конфігурація Потоків як Масив (`streams: [...]`)
- У `.nan0` потоки декларуються масивом для підтримки довільної кількості публічних, приватних та платних каналів:
  ```yaml
  streams:
    - id: private
      name: "Суверенний ізолят"
      tags: "я тіло здоровʼя побут сімʼя особисте secops ключі"
      action: isolate # залишається локально
      
    - id: pro_github
      name: "GitHub Sponsors Pro Repo"
      tags: "модель формула nan0web архітектура кібернетика код draft книга_pro"
      destinations:
        - git: "git@github.com:nan0web/inner-circle.git"
          branch: "main"
          format: "markdown"
      translate: ["en", "es"]
      
    - id: pub_github
      name: "Public GitHub Showcase"
      tags: "філософія суспільство інсайт маніфест відкриття"
      destinations:
        - git: "git@github.com:nan0web/public-diary.git"
          branch: "main"
          stripTags: true
          format: "markdown"
      translate: ["en", "es"]
  ```

### 4. Нормалізація Тегів (Рядки та Масиви)
- Теги можуть задаватися як рядок через пробіл (`"я тіло здоровʼя"`), так і масивом (`["я", "тіло"]`).
- Внутрішній нормалізатор автоматично приводить їх до множини хештегів (`Set(['#я', '#тіло', ...])`).

### 5. AST-Парсер на базі `@nan0web/markdown`
- Жодних крихких регулярних виразів для спліту документа.
- Використовується `@nan0web/markdown` AST для розбиття на структурні секції H2 (`MDHeading2`), їх контент та вкладені елементи.

### 6. Інтеграція з додатком `mova` та Глосарій Термінів
- Для перекладу публічного та розширеного шарів викликається інтерфейс `mova` (з конфігурацією з `mova.nan0` / OpenRouter / Hetzner).
- Підтримка матриці перекладів (Термінологічний словник):
  ```yaml
  glossary:
    мИть: moWeMent
    nan0web: nan0web
    Суперінтелект: Superintelligence
  ```
  За замовчуванням діє відношення 1:1 без перекладу власних понять. KaTeX-формули (`$...$`) та блоки коду залишаються недоторканими.

## 👥 User Stories (Сценарії)

1. **Як автор щоденника**, я хочу однією командою `visnyk export` відправити філософські думки у публічний доступ, а моделі й код — у платний репозиторій для спонсорів.
2. **Як розробник**, я хочу отримати повний звіт про всі пропущені теги одночасно, щоб не витрачати час на покрокове виправлення по одній помилці.
3. **Як студент курсу «Суперінтелект»**, я хочу скопіювати готову конфігурацію `_.nan0`, вказати свої репозиторії та публікувати свої артефакти без зміни коду платформи.
