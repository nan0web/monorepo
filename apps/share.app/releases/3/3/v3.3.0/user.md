# 📊 Метрики та Зворотний Зв'язок — v3.3.0

## Метрики Виконання
- **Версія:** `v3.3.0`
- **Статус:** Завершено

## Підсумки Релізу
- Реалізовано `MediaInspectorService` для виявлення та інспекції вбудованих субтитрів через `ffprobe`.
- Реалізовано `SubtitleMuxerPort` для вбудовування soft-субтитрів без перекодування відео (`stream copy`) та безпечної атомарної заміни файлів.
- Реалізовано `TranscriptCacheService` для ієрархічного дзеркального кешування транскриптів.
- Реалізовано `HFEmbeddingService` для генерації векторних ембеддінгів через Hugging Face Spaces API.
- Додано пакетну CLI-команду `DriveBatchTranscribeCommand` (`drive:batch-transcribe`).
