## 📌 Зафіксовані зауваження та реалізація (2026-11-05)

### 1. `TranscribeCommand` (CLI STT & Subtitles Pipeline)
- **Контекст:** Необхідність прямої транскрибації аудіо та відео з локальних щоденників, диктофонних записів та медійних конвеєрів без додаткових процедурних скриптів.
- **Рішення:**
  - Реалізовано `TranscribeCommand` (`src/domain/commands/TranscribeCommand.js`) як `ModelAsApp` з аліасом `transcribe`.
  - Зареєстровано в `ShareAppCLI` (`visnyk transcribe`, `share transcribe`).
  - Підтримка опції `--format` з `type: 'array', multiselect: true` (підтримує передачу списку форматів як через кому `--format text,json,sbv`, так і масивом).
  - Підтримка форматів виводу:
    - `.txt` — чистий текст для читання.
    - `.json` — структурований JSON з таймкодами слів у мілісекундах.
    - `.sbv` — YouTube SubViewer субтитри (`0:00:00.000,0:00:02.500`).
    - `.srt` — стандартні SubRip субтитри.
    - `.vtt` — WebVTT субтитри.

### 2. Zero-FS у домені та In-Memory DB тестування
- **Контекст:** Заборона процедурного `node:fs` та `node:path` у доменних модулях згідно з правилами монорепозиторію.
- **Рішення:**
  - Усі перевірки наявності файлів, нормалізація шляхів та збереження похідних документів виконуються через інжектовану базу `this.$db`.
  - Повний набір контрактних тестів у `releases/3/7/v3.7.0/task.spec.js` побудований на `@nan0web/db` In-Memory адаптері з `predefined` документами без жодних побічних ефектів на диск.

### 3. TTY & Low-Frequency Progress Throttler
- **Контекст:** Часті оновлення прогрес-бару переповнюють лог-файли та контекстне вікно агентів у non-TTY режимі.
- **Рішення:**
  - Створено фабрику `TranscribeCommand.createProgressThrottler({ isTTY, intervalMs, stepPercent })`.
  - Для interactive TTY події транслюються в реальному часі.
  - Для non-TTY / агентських сесій події троттляться (оновлення лише при стрибку відсотка $\ge 10\%$ або раз на 2 секунди, а також при $100\%$).

### 4. Ідемпотентність та кешування (`--force`)
- **Контекст:** Якщо похідні файли всіх замовлених форматів вже існують поруч із вхідним медіа, повторний запуск транскрибації є марною тратою ресурсів процесора.
- **Рішення:**
  - `TranscribeCommand` перевіряє наявність усіх цільових файлів у `$db`.
  - Якщо всі існують — файл пропускається зі статусом `skipped`.
  - Ключ `--force` примусово запускає транскрибацію та перезаписує похідні.

### 5. Архітектурне правило інжекції залежностей через `this.$`
- **Контекст:** Зауваження Архітектора: інжектовані сервіси та системні опції не повинні змішуватися з доменними полями моделі (`data`). Зайві геттери-проксі порушують DRY, а типізація не повинна скочуватися в `any`.
- **Рішення:**
  - Закріплено правило в `.agents/AGENTS.md` (Розділ 13): усі інжектовані залежності та провайдери іменуються виключно з префіксом `this.$` (наприклад, `this.$db`, `this.$UI`, `this.$whisperService`).
  - У `TranscribeCommand`:
    - Поля статичної схеми оголошені через JSDoc у конструкторі: `/** @type {string} */ this.input`, `this.format`, `this.language`, `this.quality`, `this.force`, `this.quiet`.
    - Пряме звернення до `this.$whisperService` з точним контрактом: `/** @type {typeof WhisperTranscriptionService} */ this.$whisperService = options?.whisperService || WhisperTranscriptionService` без зайвих геттерів (суворий DRY).
  - Створено беклог-паспорт [`packages/inspect/releases/backlog.md`](file:///Users/i/src/nan.web/packages/inspect/releases/backlog.md) для додавання адресного запуску `--file=<path>` та `--diff` у `nan0inspect`.
