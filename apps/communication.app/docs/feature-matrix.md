# 📊 Матриця Фіч та Мультиплікативний Скоринг (`7iOS.CoCreation`)

> **Формула пріоритетності (без плюсів — лише множення):**
> $$Score(f) = V_{\text{value}} \times A_{\text{arch}} \times I_{\text{interest}} \times E_{\text{ease}}$$
> *Де $V \in [0..10]$ (цінність), $A \in [0..10]$ (відповідність архітектурі Git + `@nan0web/db`), $I \in [0..10]$ (інтерес/місія), $E \in [0..10]$ (легкість реалізації).*
> **Правило нуля:** Якщо будь-який множник $= 0$, то $Score = 0$ (фіча відсікається).
