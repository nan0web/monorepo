# Тур Першого Дня (`7iOS` — Day 1 Onboarding)

> **Принцип:** У перший день тобі не потрібні 40 порожніх папок. Достатньо лише **4 точок опори**, які ростуть разом із твоїм життям.

## 4 Стартові Точки

1. **`i/README.md`** — твій особистий сейф (нотатки, здоров'я, ключі).
2. **`we/7i/family/todo.md`** — перший сімейний простір і спільні задачі.
3. **`we/inbox/README.md`** — вхідний карантин для нових контактів і запитів.
4. **`env/home/shopping.md`** — перший побутовий список покупок.

## Як розгорнути через CLI або VS Code

- Попередній перегляд без запису файлів:
  `nan0com init --bootstrap --dry-run`
- Розгортання стартового дерева:
  `nan0com init --bootstrap`
- Або просто відкрий цю папку у **VS Code** — файлова система і є твоїм інтерфейсом.
