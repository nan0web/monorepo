# P2P Git, Авторизація, Флешка/Пошта та Дзеркала S3 (`7iOS`)

> **Статус:** Транспортна специфікація `@nan0web/communication.app`  
> **Принцип:** Нульова залежність від GitHub/GitLab. Весь цикл працює навіть чистими bash/git-командами на Linux і macOS, а `nan0com` лише автоматизує дельти, індексацію та інтерфейс.

---

## 1. Авторизація та Публічні Ключі без GitHub

1. **Ідентичність (`soulId` + Public Key):**
   Кожен учасник має `Master soulId` і публічний ключ (`Ed25519` / SSH / GPG у `@nan0web/vault`).
   Публічні ключі учасників зберігаються прямо в репозиторії (у картках контактів `we/<circle>/<soul-slug>.md` та в реєстрі довірених ключів `allowed_signers`).
2. **Підпис кожного коміту:**
   Кожен учасник пише виключно у свою гілку `refs/heads/peers/<soulId>` і підписує коміт своїм приватним ключем. При `git fetch` пір перевіряє підпис за публічним ключем автора.

---

## 2. Vector Clock: Як ми знаємо, у кого найновіша версія?

Оскільки в гілку `refs/heads/peers/<soulId>` пише **лише один автор**, конфліктів запису не існує. Стан усього чату описується **Векторним Годинником**:
```json
{
  "peers/soul-yaro": { "head": "a1b2c3d", "seq": 142, "ts": "2026-11-20T22:00:00Z" },
  "peers/soul-friend": { "head": "f9e8d7c", "seq": 89, "ts": "2026-11-20T21:58:10Z" }
}
```
При зустрічі двох пристроїв вони порівнюють `seq` для кожного `soulId` і докачують лише відсутні коміти.

---

## 3. Транспорти (включно з Флешкою / Поштою)

1. **Прямий P2P:** LAN (mDNS), Tailscale, WireGuard, Yggdrasil, SSH або власний Caddy-сервер (`env/api/sites/`).
2. **Сліпий S3/R2-релей:** Зашифровані `git bundle` + `HEAD.json` у бакеті.
3. **Sneakernet (Флешка або Зовнішній Диск Поштою):**
   * Експорт: `git bundle create /Volumes/usb/update.bundle --all` (на зашифрованій флешці).
   * Фізична передача поштою на інший континент.
   * Імпорт отримувачем: `git fetch /Volumes/usb/update.bundle "refs/heads/peers/*:refs/remotes/usb/peers/*"`.

## 5. Скрипт Одностороннього Діода (`Tier 0` $\to$ `Tier 1` та Дзеркала)

Скрипт живе **виключно всередині зашифрованого диска `Tier 1`** і запускається після його монтування:

```bash
#!/usr/bin/env bash
set -euo pipefail

# 1. Односторонній Pull із відкритого Tier 0 у приватний архів Tier 1
TIER0_REPO="/Users/i/we/7i/family"
TIER1_MIRROR="/Volumes/tier1/mirrors/family.git"

git -C "$TIER1_MIRROR" fetch "$TIER0_REPO" "refs/heads/*:refs/heads/*"

# 2. Створення зашифрованого бандлу для зовнішніх дзеркал (S3 / R2 / інший SSD)
BUNDLE="/Volumes/tier1/tmp/family-$(date +%Y%m%d).bundle"
git -C "$TIER1_MIRROR" bundle create "$BUNDLE" --all

# 3. Шифрування та відправка на сліпе дзеркало (наприклад, rclone -> Cloudflare R2)
age -p -o "${BUNDLE}.age" "$BUNDLE"
rm -f "$BUNDLE"
# rclone copy "${BUNDLE}.age" r2:sovereign-backup/
```
