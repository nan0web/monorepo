# User Stories: llimo.v3

## Сценарії взаємодії користувача з llimo.v3

### Сценарій 1: Запуск нової сесії та привітання
- **Опис**: При запуску сесії користувачу виводиться вітальне повідомлення з унікальним ID сесії та поточною датою.
- **Вхідні дані**: Порожній ввід.
- **Очікуваний результат**:
  - `yield show` з текстом привітання.
  - `yield ask` для отримання вводу користувача.

### Сценарій 2: Обробка Boundary блоку
- **Опис**: AI модель надсилає зміни файлу в Boundary форматі, парсер витягує шлях та вміст і зберігає зміни.
- **Вхідні дані**:
  ```text
  Зміни до файлу utils.js:
  ---boundary:utils.js---
  export function sum(a, b) {
    return a + b;
  }
  ---boundary:utils.js---
  ```
- **Очікуваний результат**:
  - Файл `utils.js` створюється/оновлюється з вказаним вмістом.
  - Помилки не виникають.

### Сценарій 3: Блокування небезпечної Markdown відповіді
- **Опис**: AI модель намагається відповісти у форматі Markdown з кодом у backticks замість Boundary. Парсер відхиляє це як невалідний формат.
- **Вхідні дані**:
  ```markdown
  Here is the file:
  ```js
  export function sum(a, b) {
    return a + b;
  }
  ```
  ```
- **Очікуваний результат**:
  - Парсер виявляє markdown-блоки, маркує відповідь як невалідну.
  - Зміни до файлів не застосовуються.
  - Система надсилає AI запит з проханням переформатувати вивід у Boundary.

### Сценарій 4: Схвалення небезпечної команди (Late-Bound i18n)
- **Опис**: Команда не входить до білого списку (наприклад, `rm -rf tmp`). Система робить `yield ask` з підтвердженням.
- **Вхідні дані**: AI повертає команду `rm -rf tmp`.
- **Очікуваний результат**:
  - `yield ask` для підтвердження виконання команди.
  - Якщо користувач підтвердив, команда виконується через `OSExecutor`.
  - Якщо користувач відхилив, виконання скасовується.

### Сценарій 5: Збереження метрик у `~/.llimo/stats.jsonl`
- **Опис**: Після успішної відповіді моделі транзакція записується в аналітичний файл.
- **Вхідні дані**: Виклик моделі з параметрами: 150 вхідних токенів, 200 вихідних токенів, тривалість 1.5 сек.
- **Очікуваний результат**:
  - Новий рядок JSONL додається в `~/.llimo/stats.jsonl` з полями `modelId`, `inputTokens`, `outputTokens`, `speed`, `taskDuration`, `cost`, `efficiency`.
