# Беклог @nan0web/vault

## Заплановані можливості (Backlog)

- [ ] **BIP-39 та Вільна Фраза (12–13 власних унікальних слів):**
  - Можливість деривувати майстер-ключ не лише з фіксованого словника BIP-39 (2048 слів), а й з **будь-якої довільної фрази із 12–13 твоїх власних слів/символів** (українських, авторських, з унікальними комбінаціями). Для KDF (Argon2id/scrypt) будь-який рядок є повноцінним джерелом ентропії.
  - Підтримка опціонального 13-го секретного слова або солі (Passphrase extension).

- [ ] **Багаторівневе дно / N-Tier Duress Protocol (Динамічна поліморфна матриця N-рівнів):**
  - **Філософія нескінченного дна:** Система не має жорстко зашитого ліміту в 3 чи 4 рівні. Контейнер проектується як **N-вимірна матриця (N-Dimensional Vault)**:
    - Може бути 2, 3, 5, 10 або скільки завгодно незалежних паролів (рівнів).
    - Кожен пароль відкриває свій ізольований простір (Namespace), який не має жодних посилань на сусідні чи вищі рівні.
  - **Як унеможливити підозру про "наступний" рівень:**
    1. **Математична невразливість (Information-Theoretic Security):** Увесь файл (або картинка) — це суцільний бінарний псевдовипадковий шум (CSPRNG). Навіть якщо спецслужба знає архітектуру програми, вона математично не може визначити, скільки всередині рівнів — 1, 3 чи 10, бо порожній простір і зашифровані дані побітово невідрізні.
    2. **Протокол Розщеплення (Shamir's Secret Sharing 2-of-3 / M-of-N):** Для найвищого рівня (Рівень А) ключ не лежить в одному місці — він складається, наприклад, із твоєї фрази + відкритої стего-картинки в мережі + відбитка апаратного пристрою. Без трьох частин розшифрувати неможливо в принципі.
    3. **Панічний пароль / Dead Man's Switch (Self-Destruction):** Спеціальний пароль або дія (наприклад, введення окремої фрази), яка тихо перезаписує ключовий заголовок нулями/криптошумом на диску, безповоротно знищуючи дані Рівня А, залишаючи доступним лише Рівень В для нападників.



- [ ] **Апаратний Type-C ключ та Біометрія (Touch ID / Face ID / Secure Enclave):**
  - **Фізичний носій:** під час підключення Type-C флешки зчитується апаратний Keyfile.
  - **Біометрична сесія:** після введення пароля ключ шифрування тимчасово (наприклад, на 15–30 хвилин) поміщається у захищений анклав ОС (Touch ID / Face ID / PIN-код).
  - **Автоблокування (Zero-Trace Lock):** при витяганні Type-C флешки, переході в сплячий режим або завершенні таймера сесії оперативна пам'ять миттєво зануляється (`Buffer.fill(0)`), і сховище блокується.

- [ ] **Стеганографічний публічний носій (Stego Vault у PNG/WebP):**
  - Упаковка зашифрованої бази в звичайне зображення без візуальних спотворень.
  - Можливість відкрито розміщувати картинку на GitHub, в аватарах або децентралізованих мережах.

- [ ] **Децентралізоване вічне збереження та анонімні сервери:**
  - Детальний аналіз наведено нижче у розділі інженерного порівняння.

| **Принцип роботи** | Блокчейн з Proof of Access.
