# 🎯 Адресний аудит та Scoped / Git-Diff режим (`--file`, `--diff`)

> **Статус:** Planned / Backlog  
> **Пакет:** `@nan0web/inspect`  
> **Компоненти:** `InspectorApp`, `AuditorModel`, `JsDomainAuditor`  

---

## 🎯 Проблема

У великих монорепозиторіях або додатках зі спадковим кодом `nan0inspect` (зокрема `JsDomainAuditor`) сканує абсолютно всі файли `src/domain/**`. Повідомлення про застарілі класи переповнюють буфер виводу консолі, що маскує помилки поточного релізу і змушує агента працювати наосліп.

---

## 📋 Вимоги та Функціонал

1. **Підтримка CLI прапорця `--file=<path>`:**
   - Запуск перевірки для одного конкретного файлу або папки (наприклад, `nan0inspect domain --file=src/domain/commands/TranscribeCommand.js`).
2. **Підтримка `--staged` або `--diff`:**
   - Перевірка виключно тих файлів, що змінені в поточній git-гілці або індексі релізу.
3. **Лаконічний звіт:**
   - Фокусування результату без спаму повторюваними повідомленнями для сторонніх файлів поза областю diff.
