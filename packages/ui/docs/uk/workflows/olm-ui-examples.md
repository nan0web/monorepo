# Приклади розробки OLMUI додатків (Model-as-App)

Цей документ містить посилання на **канонічні, реально працюючі** приклади побудови додатків на базі архітектури **NaN•Web OLMUI** у нашому монорепозиторії. Використовуйте ці файли як шаблони при розробці нових доменних моделей, адаптерів та CLI/Web інтерфейсів.

---

## 1. Базовий Додаток-Виконавець (InitProjectModel)

Приклад простого додатку, який отримує аргументи з CLI, перевіряє директорії та виконує встановлення залежностей через системні команди.

- **Файл:** [InitProjectModel.js](apps/llimo.app/src/domain/app/InitProjectModel.js)
- **Що варто вивчити:**
  - Використання статичних полів (`dir`, `lang`, `quiet`) для опису аргументів `Model-as-Schema`.
  - Збереження локалізованих повідомлень у статичному об'єкті `UI`.
  - Ініціалізація та використання бази даних `this._.db` (DBFS) для створення структури проекту.
  - Використання `yield show(...)` та `yield progress(...)` для виводу інформації.

---

## 2. Головний Маршрутизатор Додатку (LlimoApp)

Приклад складного додатку з багатьма підкомандами, який виступає як точка входу та маршутизатор команд (Router -> Executor).

- **Файл:** [LlimoApp.js](apps/llimo.app/src/domain/app/LlimoApp.js)
- **Що варто вивчити:**
  - Реєстрація масиву підкоманд у `static command = { options: [...] }`.
  - Патерн делегування виконання: `if (this.command) return yield* this.command.run()`.
  - Монтування додаткових модулів (наприклад, `@chat`) до `this._.db` у конструкторі.

---

## 3. Оркестратор Складних Процесів (PipelineModel)

Приклад додатку, який керує тривалими багатоетапними процесами (як-от ап-пайплайн) в циклі.

- **Файл:** [PipelineModel.js](apps/llimo.app/src/domain/PipelineModel.js)
- **Що варто вивчити:**
  - Послідовний запуск інших команд (наприклад, `PipelineCommand`) у циклі `for`.
  - Обробка результатів виконання кожної команди (`val.type === 'result'`).
  - Передача контексту `this._` дочірнім командам при їх ініціалізації.

---

## 4. Складний Аналітичний Додаток (PrepareApp)

Приклад додатку, що збирає контекст монорепозиторію, читає маніфести `nan0web.nan0`, генерує `.gemini/prompt.md` та зберігає стан сесії.

- **Файл:** [PrepareApp.js](src/domain/app/PrepareApp.js)
- **Що варто вивчити:**
  - Асинхронне зчитування та обробка багатьох конфігураційних файлів (`db.loadDocument`, `db.stat`).
  - Генерація markdown-документів на льоту та їх запис у файлову систему.
  - Інтеграція з іншими OLMUI додатками (наприклад, виклик `BuildWorkflowsApp.execute`).

---

## 5. Написання Сценарних Тестів (ScenarioTest)

Замість імітації CLI чи браузера, тестування `ModelAsApp` відбувається шляхом перевірки потоку намірів (intents), які генерує додаток.

- **Файли:**
  - [ChatSessionModel.test.js](apps/llimo.app/src/domain/app/ChatSessionModel.test.js)
  - [TranslateDocsModel.test.js](apps/llimo.app/src/domain/app/TranslateDocsModel.test.js)
  - [PipelineModel.test.js](apps/llimo.app/src/domain/PipelineModel.test.js)
- **Що варто вивчити:**
  - Ініціалізація `ModelAsApp` із тестовими параметрами.
  - Виклик `app.run()` і перевірка послідовності `yield` за допомогою `await iter.next()`.
  - Перевірка фінального результату `status` та даних, які повертаються в `result(...)`.
