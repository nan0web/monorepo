# 📜 Контракт Декларативних Даних: `$content` та `content`

> **Пакет:** `@nan0web/ui`  
> **Концепція:** One Logic — Multiple User Interfaces (OLMUI)  
> **Еталонний рендерер:** `Element.render(input, key, context)`

---

## 🏛 1. Фундаментальний Принцип Фрактальності

У системі OLMUI **немає штучного бар'єру між «рівнем сторінки» та «рівнем компонента»**:
- `Document.$content` — кореневий масив декларативних блоків сторінки.
- `Content.content` або `Element.content` — внутрішній масив блоків будь-якого контейнера (`Card`, `Tabs`, `Dialog`, `Layout`).
- **Усі вони обробляються абсолютно однаково через `Element.render`**.

---

## 🧩 2. Анатомія Блоку Контенту

Блок контенту — це звичайний об'єкт JavaScript або YAML-нода наступної структури:

```yaml
# 1. Базовий HTML-тег або семантичний компонент:
h2: "Заголовок розділу"
$class: "section-title"

# 2. Компонент-контейнер з вкладеним content:
Card:
  $variant: "primary"
  $onClick: "submit"
  content:
    - h3: "Калькулятор послуги"
    - p: "Оберіть параметри нижче:"
    - App.Calculator: true

# 3. Булевий шортхенд (підтягування даних із моделі документа):
Hero: true       # Рівнозначно вичитуванню this.hero з Document
Banner: true     # Рівнозначно вичитуванню this.banner з Document
```

### Синтаксичні правила:
1. **Назва компонента або HTML5 тегу (Ключ без `$`)**:
   - Маленькі літери (`h1`, `h2`, `p`, `div`, `ul`, `li`, `span`) — стандартні семантичні HTML5 теги.
   - Велика літера (`Card`, `Button`, `Markdown`, `Table`, `Alert`) — OLMUI-компоненти з реєстру компонентів теми.
   - Префікс `App.` (`App.LoanCalculator`, `App.RegisterForm`) — інтерактивний автономний додаток `ModelAsApp`.
2. **Властивості, події та модифікатори (Ключі з префіксом `$`)**:
   - `$class` / `$className` — стильові класи.
   - `$variant` — варіант оформлення (`primary`, `secondary`, `danger`, `outline`).
   - `$on<Event>` / `$onClick` — дія чи обробник події.
   - `$aria*` — доступність для скрінрідерів.
3. **Значення (Value)**:
   - `string` / `number` — прямий текстовий контент.
   - `true` — пустий блок або директива підтягування поля з батьківської моделі документа.
   - `array` (`content: [...]`) — рекурсивний масив дочірніх блоків.

## 🔄 3. Наскрізна Мультимодальна Проекція `Element.render`

Один і той самий масив `$content` / `content` матеріалізується наскрізно в усіх середовищах:

| Блок у `content` | Web (`@nan0web/ui-react`) | Terminal (`@nan0web/ui-cli`) | Terminal (`@nan0web/ui-tui`) | Chat (`@nan0web/ui-chat`) | Voice (`@nan0web/ui-voice`) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `h2: "Заголовок"` | `<h2>Заголовок</h2>` | ANSI Bold `\x1b[1mЗаголовок\x1b[0m` | Заголовок вікна / Box title | Текст `## Заголовок` | Пауза + підвищений тон |
| `Card: { content: [...] }` | `<div className="card">` | Рамка `┌──┐` (Box) | Віконний фрейм з рамкою | Окремий блок / повідомлення | Зачитування блоку цілком |
| `App.Name: true` | Неблокуючий `AppRunner` | Потоковий генератор (stdin) | Повноекранне модальне вікно | Інтерактивний діалог (ask) | Послідовне опитування голосом |
