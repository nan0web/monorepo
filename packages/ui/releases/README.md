## 🎮 Як переглянути релізи у різних інтерфейсах

```bash
# 🌐 WEB: відкрити інтерактивний веб-каталог релізів
pnpm exec serve releases/

# 💻 CLI: відкрити термінальне меню вибору версій
pnpm exec release

# 🖥️ TUI: запустити повноекранний термінальний інтерфейс
pnpm exec release --tui

# 💬 CHAT: запитати ШІ про фічі та історію змін
pnpm exec release --chat "Які нові контракти додано у версії 3.4.0?"
```
